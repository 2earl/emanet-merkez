# Emanet Merkez

The 2earl staff console for Emanet at **emanet-merkez.2earl.com**: partners, agents and their
verification, the review queue, deliveries, invoices, receipts and payouts. Only login staff
(admin, support) can sign in.

Built on [Emanet core](https://github.com/2earl/emanet-core); sign-in with login.2earl.com.
